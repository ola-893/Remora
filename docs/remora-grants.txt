Remora execution grants
=======================

On NEAR testnet, approve one funding transfer in Meteor. Remora generates a
key for the separate implicit execution account and stores it locally. Your
owner wallet remains the signer for operations on your owner account.

Run these commands from a project with a named agent and a connected testnet wallet.

  agentstream grant create --agent my-agent --transactions 7 --hours 1 \
    --activities portfolio-rebalance --tokens wrap.testnet,rft.tokenfactory.testnet --fund-near 0.15
  agentstream grant prepare --agent my-agent --activity portfolio-rebalance \
    --token wrap.testnet --balance-raw 20000000000000000000000
  agentstream grant show

The preparation target is the minimum desired balance. It is an exchange
balance for rebalance and an execution-wallet balance for the other activities.
Preparation can register storage, wrap test NEAR and deposit on Rhea Exchange.
Each submitted preparation or strategy transaction consumes one grant slot.
For a concentrated-liquidity range, prepare the token and DCL storage before
running task deposit-range from the same grant. Staking uses native test NEAR.

Configure the agent's execution guard and then use task run or agent run
--prompt to request actions. A copied action in approval mode still needs
copy approve. A matching grant signs the approved transaction without opening
Meteor again. Spot trading has its own NEAR Intents execution path.

Only one grant can be active for a connected owner. It is bound to the named
agent and selected activities. Remora enforces the count, expiry, venue and
method locally. The execution key has full access to the separate account,
including assets deposited later and any trading gains. Keep owner funds
separate. A production design with enforceable expiry and spending limits
requires a policy contract holding the funds and an access key scoped to
calling that contract.

When a grant stops, its account and positions stay available for recovery.
Run grant revoke to recover supported balances and retire the account. A
pending settlement, unreadable venue, or staking unbonding period can prevent
immediate recovery. Use grant reconcile for an uncertain execution transaction
and wallet reconcile for an uncertain initial funding transfer.

Inference
=========

  agentstream inference set --provider local --model MODEL
  agentstream inference models --provider near-ai
  agentstream inference set --provider near-ai --model MODEL --api-key

Local inference uses an OpenAI-compatible service on loopback. NEAR AI uses
the fixed Cloud Gateway and checks the live catalog for tool support and
provider-reported verifiability and attestation support. The API key is
entered through the CLI's hidden input. The CLI emits response IDs when
available for independent verification. Catalog eligibility and a response
ID do not verify the attestation for that response.

NEAR AI verification instructions
https://docs.near.ai/cloud/verification
